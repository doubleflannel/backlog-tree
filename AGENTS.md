# Backlog Tree

A local terminal companion for existing Backlog.md projects. No server or database.
Read Markdown safely; delegate live task edits and views to the installed Backlog CLI.
Never rewrite task files or patch the installed Backlog package.
Person labels describe one main person, not the assignee. Missing person means Internal.
Keep family ancestry across statuses; completed-folder files are read-only history.
Run node tests and the PTY interaction checks before changing the local install.
